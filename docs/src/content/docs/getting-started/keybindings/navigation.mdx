## `↑` - Move Up

Press <kbd>↑</kbd> to move to the previous work item in the current section.

## `↓` - Move Down

Press <kbd>↓</kbd> to move to the next work item in the current section.

## `Shift+Tab` - Previous Section

Press <kbd>Shift</kbd>+<kbd>Tab</kbd> to move to the previous section in the current view.
<kbd>[</kbd> is also supported as a legacy alias.

## `Tab` - Next Section

Press <kbd>Tab</kbd> to move to the next section in the current view.
<kbd>]</kbd> is also supported as a legacy alias.

## `g/home` - First Item

Press <kbd>g</kbd> or <kbd>Home</kbd> to move to the first work item in the current section.
<kbd>&lt;</kbd> is also supported as a legacy alias.

## `G/end` - Last Item

Press <kbd>G</kbd> or <kbd>End</kbd> to move to the last work item in the current section.
<kbd>&gt;</kbd> is also supported as a legacy alias.
