## `p` - Cycle Preview Pane

Press <kbd>p</kbd> to cycle the preview pane between vertical split, horizontal split, and hidden.

## `f` - Focus Preview Pane

Press <kbd>f</kbd> to focus the preview pane when it is open.

## `F` - Focus Main Pane

Press <kbd>F</kbd> to return focus to the main pane.

## `up`/`down` - Scroll Preview

When the preview pane is focused, press <kbd>↑</kbd>/<kbd>↓</kbd> to scroll the preview.

## `PgUp`/`PgDn` - Page Active Pane

Press <kbd>PgUp</kbd>/<kbd>PgDn</kbd> to page up or down in the focused pane.
<kbd>Shift</kbd>+<kbd>↑</kbd>/<kbd>Shift</kbd>+<kbd>↓</kbd> and
<kbd>Ctrl</kbd>+<kbd>↑</kbd>/<kbd>Ctrl</kbd>+<kbd>↓</kbd> are also supported as aliases.

## `g`/`G` - Preview Top/Bottom

When the preview pane is focused, press <kbd>g</kbd> to jump to the top or <kbd>G</kbd> to jump to the bottom.

## `left`/`right` - Previous/Next Preview Tab

When the preview pane is focused, press <kbd>←</kbd> or <kbd>→</kbd> to move between preview tabs, if tabs are available.
